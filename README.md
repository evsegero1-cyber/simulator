# Управленческий симулятор

Офлайн-приложение для Android: обучение менеджменту через управление виртуальным предприятием.
Пошаговая игра (1 ход = 1 месяц), 5 отраслей, 49 управленческих ситуаций с разбором по теории менеджмента,
годовые отчёты руководителя и итоговая оценка компетенций. Без ИИ и интернета.

## Сборка APK
1. Загрузите содержимое архива в корень репозитория GitHub (папки `app`, `.github` и файлы `build.gradle`, `settings.gradle`, `gradle.properties`).
2. GitHub Actions соберёт APK автоматически при пуше в `main` (или вручную: Actions → Build APK → Run workflow).
3. Скачайте артефакт `UpravSim-apk` и установите `UpravSim.apk`.

Постоянный ключ подписи хранится в секрете репозитория `KEYSTORE_B64` (Settings → Secrets and variables → Actions).
Если секрет задан, новые версии ставятся поверх старой без потери сохранений; без него APK подписывается временным ключом.

## Структура
- `app/src/main/assets/www` — само приложение (HTML/CSS/JS), его можно открыть и в браузере: `index.html`.
  - `js/core` — утилиты, детерминированный генератор случайных чисел (хранится в сохранении).
  - `js/data` — отрасли, справочники, теория менеджмента, база ситуаций.
  - `js/engine` — модель данных, экономический движок месяца, действия игрока, ситуации, отчёты, сохранения.
  - `js/ui` — интерфейс: каркас, графики, экраны.
- `app/src/main/java/.../MainActivity.java` — WebView-оболочка, кнопка «Назад».

## Экономическая модель (кратко)
Спрос рынка (база × экономический цикл × ключевая ставка × сезонность × рынки × ассортимент) делится между
вами и конкурентами по логит-модели привлекательности: цена, качество, репутация, узнаваемость, новизна, работа продаж.
Выпуск ограничен выработкой персонала (квалификация, удовлетворённость, стиль контроля, руководители, координация,
оборудование) и мощностью оборудования. Удовлетворённость считается по Герцбергу (гигиена + мотиваторы),
текучесть — от удовлетворённости и зарплаты к рынку. Затраты: материалы, ФОТ и взносы, накладные, обслуживание,
маркетинг, обучение, качество, хранение, логистика, амортизация, проценты, налоги (с переносом убытков).
Деньги отличаются от прибыли: дебиторка, запасы, капитальные вложения, кредиты.
Поражение: банкротство (овердрафт выше лимита банка), потеря рынка, критическая текучесть.
